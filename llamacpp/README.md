# llama.cpp 🦙

[![Source: llama.cpp](https://img.shields.io/badge/Source-llama.cpp-blue?logo=git)](https://github.com/ggml-org/llama.cpp)

![screenshot](https://thumb.wikimedia.org/wikipedia/commons/thumb/5/5f/Llama.cpp_screenshot.png/960px-Llama.cpp_screenshot.png?utm_source=commons.wikimedia.org&utm_campaign=index&utm_content=thumbnail&_=20260608042616)

[llama.cpp](https://github.com/ggml-org/llama.cpp) provides local LLM inference with an OpenAI-compatible API and the Llama Chat web interface.

This app runs `llama-server` in **model router mode**, with:

- Multiple GGUF models loaded on demand
- The built-in chat and model-management Web UI through Home Assistant ingress
- Persistent models and Hugging Face downloads under `/data`
- Configurable model count, memory margin, context, and parallelism
- Optional API key authentication and direct API access
