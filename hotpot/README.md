![Hotpot heatmap](https://user-images.githubusercontent.com/188935/273125894-7f76eabb-585b-405d-af16-a93df2d85cb4.png)

[Hotpot](https://github.com/erik/hotpot) renders customizable activity heatmaps from GPS tracks in GPX, TCX, and FIT files. It includes a web interface, an XYZ tile server, activity inspection, image rendering, and optional activity uploads.

## Main features

- Import and visualize GPS activities locally.
- Customize heatmap colors and filter activities by their metadata.
- Hide sensitive areas with configurable privacy masks.
- Upload activities from the browser or fetch them from intervals.icu.
- Optional Strava webhook integration.
- Home Assistant Ingress and optional direct HTTP/HTTPS access through the shared app proxy.
