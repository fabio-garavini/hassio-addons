# Home Assistant app: Audiobookshelf 🎧 by Fabio Garavini

[![](https://img.shields.io/static/v1?label=Support+me&message=%E2%9D%A4&logo=GitHub&color=%23fe8e86)](https://github.com/sponsors/fabio-garavini)

Audiobookshelf is a self-hosted audiobook and podcast server.

It bundles everything you need (database, metadata storage, web UI, mobile
streaming) into a single container that runs as a Home Assistant app — no
external database to install, no reverse proxy to configure.

![screenshot](https://github.com/advplyr/audiobookshelf/raw/master/images/DemoLibrary.png)

## ✨ Features

- **All-in-one** — database, metadata, web UI and streaming server in a
  single app
- **Audiobooks & podcasts** — manage your library in one place
- **Multi-user** — invite family or friends with their own accounts and
  per-user progress
- **Mobile-friendly** — works great with the official Audiobookshelf apps
  for iOS and Android
- **Open source** — built on the
  [Audiobookshelf](https://www.audiobookshelf.org/) project

## 📥 Installation

1. Make sure this repository is added to your Home Assistant app store.
2. Install the **Audiobookshelf** app.
3. Start the app and open the Web UI.
4. Create your admin account on first launch.
