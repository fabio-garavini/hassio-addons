# ownCloud ☁️

[![Source: ownCloud](https://img.shields.io/badge/Source-ownCloud-blue?logo=git)](https://owncloud.com/)

## Install

- Install ownCLoud
- Set `Admin User` and `Admin Password` configurations
- Start it and open web ui

## Limitations

At the moment if you want to change the `Storage Location` you can do it **only before running the addon for the first time**
