## Highlights

- **A dock for every library**: Book Dock is now the Library Dock. Turn on a dock for any library and BookOrbit makes a folder for it, where dropped files are fetched, named and filed by that library's own rules: match threshold, metadata mode, destination folder and keeping originals for seeding. Every waiting file says why, and an upload can go to the dock first or file now. <!-- icon: Inbox -->
