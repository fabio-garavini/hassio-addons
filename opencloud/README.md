# OpenCloud ☁️

[![Source: OpenCloud](https://img.shields.io/badge/Source-OpenCloud-blue?logo=git)](https://opencloud.eu)

OpenCloud is an open-source project that gives you a secure and private way to store, access, and share your files

![image](https://raw.githubusercontent.com/opencloud-eu/.github/refs/heads/main/profile/web-ui-gallery-view-optimized.jpg)

**Benefits**

| 🤝 **Collaboration**               | 🔒 **Data Privacy**              | ⚙️ **Simplicity**                          |
|------------------------------------|----------------------------------|--------------------------------------------|
| OpenCloud provides tools to help everyone work together, no matter where they are. | Your data stays with you, reducing the risk of unauthorized access or third-party breaches. | Minimize maintenance efforts while bringing the convenience of SaaS to your self-hosted cloud on-premises. |

## Pre-installed apps

Bundled inside this OpenCloud app for Home Assistant there are the following extensions:

✅ Unzip - managing zip files

✅ Maps - display `.gpx` files and show geo location data for pictures

✅ JSON Viewer - View JSON files (.json) with syntax highlighting and collapsible nodes

✅ Draw.io - View and edit draw.io diagram files

✅ Progress Bars - A collection of progress bars for users to choose from
