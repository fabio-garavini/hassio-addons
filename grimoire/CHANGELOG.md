# v1.1.0

> [!WARNING]
> Grimoire 1.0 is a complete rewrite of the application and introduces breaking changes.
> It is **not possible to migrate automatically** from the previous 0.4/0.5 versions: bookmarks, categories, tags and media stored by the old app will not be imported.
> Before updating, make a backup of the app, then reinstall it removing all the previous data and create a new user account.
